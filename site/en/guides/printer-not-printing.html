Printer not printing?

Follow the document from the queue to the paper.

Manual steps · Windows 10/11Guide 1.0 · Reviewed 19 Nov 2026

What is happening

Your document stays in the queue, prints on the wrong printer, or the device appears offline.

01

Diagnose

  1. Check the printer display: power, paper, ink/toner and messages. Confirm the USB cable or the intended network connection.
  2. In Settings → Bluetooth & devices → Printers & scanners (Windows 11), select the intended printer. On Windows 10, search Settings for Printers & scanners. Check its name and open the queue.
  3. Check whether the document was sent to Microsoft Print to PDF or another printer. If colleagues can print, focus on your computer and application.
02

Fix manually

  1. Explicitly select the right printer in the print dialog. Test a simple page first and do not repeatedly submit the same job.
  2. In the queue, cancel only your own stuck jobs after saving the document. Do not delete other people's jobs or clear a shared server queue.
  3. If needed, use Windows printer diagnostics and review the changes. For driver installation or replacement, use Windows Update or the exact manufacturer, with IT approval on a managed PC.
03

Check the result

  1. In Printer properties, send a test page. Then print one page from the original app.
  2. Confirm the queue has cleared, only the requested copies printed, and paper size, orientation and colour are correct.

What changes and how to undo it

Cancelling removes a job from the queue; you must submit it again. It does not delete the original document. Leave driver or shared-queue changes to IT.

Optional tools

Use the print queue and built-in Windows tools. SpeedDisc is not presented here as a printer repair tool.

When to stop and ask for help

If the printer reports a hardware fault or a confidential job appears elsewhere, stop and contact the owner. Do not publish documents or student data when asking for help.

Reference and further reading

Based on Windows options and the linked documentation. Menu names vary by version. This guide does not guarantee a fix for every cause.

Microsoft Support

On a managed computer, confirm changes with the owner. Never share passwords or personal data in a support request.
