NETWORK / MANUAL GUIDE

Wi-Fi connected. No internet.

Separate a computer problem from a network problem.

What is happening

Your computer is connected to Wi-Fi, but pages will not load or Windows says “No internet”.

01

Diagnose

  1. Check the network name. Open two familiar websites. If only one fails, that website may be the problem rather than your connection.
  2. Test another device on the same Wi-Fi with mobile data disabled. If both fail, check for a provider outage or a router issue with the network owner.
  3. On a guest network, open the browser and look for the official sign-in portal. Do not bypass certificate warnings or enter credentials on a suspicious page. Note whether only one computer is affected.
02

Fix manually

  1. Save your work. Turn Wi-Fi off and on on your own computer. Restart the computer if the issue continues.
  2. On a personal network, if you know the password, you can forget that network in Settings → Network & internet → Wi-Fi → Manage known networks and reconnect. Ask IT first on a managed school network.
  3. If all devices fail, ask the owner to check the router/provider. Do not restart shared equipment during lessons. Use Windows Network and Internet troubleshooting and review proposed changes before accepting.
03

Check the result

  1. Open two websites again and test the app you need. Confirm you are on the intended Wi-Fi, not mobile data.
  2. If it still fails, tell support the network name, time, error message and affected devices. Do not send passwords.

What changes and how to undo it

Reconnecting briefly interrupts the connection. Forgetting a network removes its saved profile and requires credentials to reconnect. This guide does not change DNS, proxy, VPN or security rules.

Optional tools

Use Windows Settings and built-in diagnostics. No SpeedDisc download or third-party network repair tool is required.

When to stop and ask for help

If your connection uses a VPN, certificate, school authentication or proxy settings, do not reset the network without your administrator.

Reference and further reading

Based on Windows options and the linked documentation. Menu names vary by version. This guide does not guarantee a fix for every cause.

Microsoft Support

On a managed computer, confirm changes with the owner. Never share passwords or personal data in a support request.
