Ferramenta de técnico

Menos ruído no Windows, sem promessas vazias.

O SpeedDisc é um único ficheiro portátil. Limpa lixo seguro, pode correr o SFC e o DISM, e escreve um relatório curto do que encontrou, do que fez e do que falhou.

Descarregar SpeedDisc.exe Código fonte

Versão 0.4.0 · um executável · sem instalador · licença MIT · Windows de 64 bits.

O que faz

Um ficheiro

Cabe numa pen. Duplo clique, o Windows pede administrador, e aparece um menu de consola. Não há assistente de instalação.

Português e inglês

O português europeu é a língua inicial quando o navegador está em português. Inglês, quando está em inglês. Dá para mudar aqui e no menu do programa. O relatório segue a língua escolhida.

Relatório curto

No fim fica um texto UTF-8 ao lado do programa: data, o que foi encontrado, o que foi feito e o que falhou.

Pacotes

Também dá para marcar ações uma a uma, com números separados por vírgulas. Os pacotes são atalhos.

01

Rápido

Temporários, cache de transferências do Windows Update, miniaturas e plano de energia Alto desempenho.

02

Profundo

O conjunto rápido, mais Delivery Optimization, relatórios de erros, SFC e DISM. Ponto de restauro se o Windows deixar. Não desativa o arranque e não esvazia a Reciclagem.

03

Só ver

Sistema, processador, memória, discos, arranque e uma estimativa dos temporários. Não altera nada.

04

Completo

Temporários, cache de transferências do Windows Update, miniaturas, Delivery Optimization, relatórios de erros, plano Alto desempenho, SFC e DISM. Cria primeiro um ponto de restauro, se o Windows deixar. Não desativa o arranque e não esvazia a Reciclagem.

À escolha

Temporários, cache do Windows Update (só a pasta Download), miniaturas, Delivery Optimization, plano Alto desempenho, relatórios de erros, SFC, DISM, ponto de restauro e informação do sistema. O pacote completo corre estas ações que alteram o PC, com ponto de restauro primeiro, e não desativa o arranque nem esvazia a Reciclagem. No arranque, lista as chaves Run e as pastas de arranque e só desativa o que o técnico escolher.

O que não faz

De propósito

  • Não mostra percentagens de velocidade.
  • Não desativa serviços, incluindo o SysMain.
  • Não apaga a pasta Prefetch.
  • Não esvazia a Reciclagem.
  • Não desativa o arranque sozinho.
  • Não é um limpa-registo.
  • Não instala nada e não pede conta.

Aberto

O código está no GitHub, licença MIT. Dá para ler o que cada ação apaga antes de o correr num computador de cliente. O executável publicado é o mesmo programa, compilado para Windows de 64 bits.

Como correr

  1. 1Copie o SpeedDisc.exe para o computador ou para uma pen USB.
  2. 2Duplo clique. O Windows pede administrador antes do menu.
  3. 3Escolha um pacote ou vários números. Leia o relatório .txt que fica ao lado do programa.

Kits e Perfis

Pequenos launchers (.cmd) que executam SpeedDisc.exe com perfis pré-configurados. Copie o launcher + SpeedDisc.exe para a mesma pasta.

UM SÓ SpeedDisc.exe — os launchers apenas o chamam com opções diferentes.

SpeedDisc-Escola

Limpeza rápida sem operações longas. Para escolas e contextos onde o tempo é limitado.

Faz: Temporários, cache WU, miniaturas, plano Alto desempenho

Não faz: SEM SFC/DISM (demoram). Não desativa arranque nem esvazia Reciclagem.

Descarregar launcher

SpeedDisc-PosFormatacao

Manutenção profunda após instalação do Windows. Inclui SFC e DISM (podem demorar 15-30 min).

Faz: Limpeza completa, SFC, DISM, ponto de restauro

Não faz: Não desativa arranque nem esvazia Reciclagem.

Descarregar launcher

SpeedDisc-SoVer

Inventário apenas: lê sistema, arranque e discos. NÃO altera nada.

Faz: OS, CPU, memória, discos, arranque, estimativa de temporários

Não faz: Não altera NADA no sistema. Apenas lê e escreve relatório.

Descarregar launcher

SpeedDisc-USB

Perfil para pen de técnico: limpeza rápida para visitas de suporte.

Faz: Temporários, cache WU, miniaturas, plano Alto desempenho

Não faz: SEM SFC/DISM. Não desativa arranque nem esvazia Reciclagem.

Descarregar launcher

Capacidades de diagnóstico

SpeedDisc oferece ações de diagnóstico e manutenção sem alterar o sistema:

Diagnóstico

  • Inventário: sistema, CPU, memória, discos, arranque
  • Ficheiros maiores: lista os top 20 ficheiros
  • Arranque: lista Run keys e pastas Startup
  • Rede: (planeado) snapshot IP, DNS, gateway
  • Bateria: (planeado) relatório powercfg

Manutenção

  • Limpeza segura: temporários, cache WU/DO
  • Reparação: SFC, DISM, Component Store
  • Rede: Flush DNS, Winsock reset

NÃO oferece: limpa-registo, percentagens falsas, matar processos, esvaziar Reciclagem por omissão, desativar SysMain.

Aviso do SmartScreen esperado

O executável não está assinado por escolha

O Windows vai mostrar "O Windows protegeu o PC" quando executar o ficheiro pela primeira vez. Isto é normal e esperado para programas sem certificado comercial.

Como proceder:

  1. Clique em "Mais informações"
  2. Clique em "Executar mesmo assim"

A reputação do ficheiro melhora com o número de transferências ao longo do tempo. Eventualmente o SmartScreen pode deixar de avisar, mas o aviso inicial é previsto e seguro de ignorar quando o ficheiro vem do GitHub oficial.

Para escolas e secretárias de IT

Frase de suporte para técnicos que entregam uma pen com o SpeedDisc:

"Este programa mostra um aviso do Windows porque não tem assinatura digital paga. É código aberto do GitHub. Clique em 'Mais informações' e depois 'Executar mesmo assim'. O relatório fica ao lado do ficheiro."
